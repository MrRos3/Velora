# Velora — Opus 🥀

Velora v0.7.0 **Opus** is a rounded Roblox piano workstation with Lucide icons, static playback controls, and complete MIDI-derived arrangements.

## Run the cache-breaking release

```lua
loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/MrRos3/Velora/main/boot-070.lua",
    true
))()
```

## Opus 0.7.0

- Static play button with no per-note pulse animation
- 13 complete arrangements with explicit notes, chords, rests, and twelve timing steps per beat
- New: Canon in D, Minute Waltz, Fantaisie-Impromptu, Pathétique Adagio, Mozart K.545 Allegro, and Ode to Joy
- Long-form favorites include Clair de Lune, Moonlight Sonata, Canon in D, and Pathétique Adagio
- Lucide icons throughout; 🥀 remains the only interface emoji
- Draggable progress, BPM adjustment, RGB and HEX theming
- Stops at each song’s ending unless Loop is enabled

## Music sources

Arrangements are generated from credited Mutopia MIDI editions. The source URL and edition license are stored inside every song file. Most editions are public domain. Canon per 3 Violini e Basso is credited to typesetter Michael Fischer v. Mollard and distributed under CC BY 4.0.

Before pressing Play, click the in-game piano once so it owns keyboard focus.
