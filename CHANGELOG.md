# Changelog

## 0.3.0 — Nocturne

- Added the new independent premium standalone `latest.lua`
- Added three-zone library / browser / now-playing layout
- Added favorites, recents, queue, category filters, search, and random selection
- Added queue autoplay, shuffle, loop, seek, speed, and BPM controls
- Added live piano-key visualizer
- Added optional executor / virtual keyboard input backend with preview fallback
- Added `Velora:BindPiano(callback)` and public runtime API
- Added GitHub-backed lazy song loading from `Songs.lua`
- Added responsive scaling, dragging, RightShift toggle, and mini-player
- Added Lucide icon support from `MrRos3/Icons`
- Added stable `loader.lua` and loadstring example
- Kept the implementation original and independent of TALENTLESS source code
